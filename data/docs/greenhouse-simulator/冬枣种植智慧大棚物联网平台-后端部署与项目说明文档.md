## 一、项目概述

### 1.1 项目简介

本项目基于 **RuoYi-Vue 3.9.2** 框架进行二次开发，构建了一个面向冬枣种植场景的智慧大棚物联网数据采集与管理平台。后端采用 **Spring Boot 4.0.3 + MyBatis** 架构，集成 PostgreSQL、TDengine、Valkey、MQTT 等多种数据库与中间件，实现了从传感器数据采集、存储、分析到预警的全链路闭环。

**核心定位**：纯数据管理与监测平台，不涉及 AI 预测决策与设备自动控制。

### 1.2 功能概述

| 功能模块 | 说明 |
|---------|------|
| 数据采集 | 通过 MQTT 协议接收传感器数据，经质量校验后写入时序数据库 |
| 数据存储 | TDengine 存时序数据、PostgreSQL 存业务数据、Valkey 缓存实时数据 |
| 业务管理 | 大棚/设备/物候期/阈值等基础数据的增删改查 |
| 智能预警 | 6 大类预警引擎，4 级分级，7 状态闭环管理 |
| 统计分析 | 描述性统计、对比分析、相关性分析 |
| GIS 空间查询 | PostGIS + GeoJSON，大棚点位/区域边界/聚合统计 |
| 自动化报表 | Excel + PDF 双格式日报，自动上传阿里云 OSS |
| 告警推送 | 实时推送 + 定时重试，Redis 去重 |
| 日志审计 | 操作审计、告警记录、推送记录全链路可追溯 |

## 二、系统架构

### 2.1 整体架构

```
端层（数据源）
├── 环境传感器（温度/湿度/光照/CO₂/风速）
├── 土壤传感器（含水率/EC/pH/土壤温度）
└── 边缘数据网关（协议适配/本地缓存/断网补传）

     │ MQTT over TLS
     ▼

云层（数据中枢）
├── 数据接入：EMQX MQTT Broker
├── 数据处理：MqttConsumer → DataQualityChecker → AlarmEngine
├── 数据存储：TDengine（时序）+ PostgreSQL（业务）+ Valkey（缓存）
├── 对象存储：阿里云 OSS（日报/图片）
├── REST API：14 个 Controller / 约 74 个接口
└── 报表服务：EasyExcel + PDFBox + JFreeChart
```

### 2.2 Maven 模块结构

```
ruoyi（根项目）
├── ruoyi-admin          # 后端启动入口（端口 8080）
├── ruoyi-iot            # ☆ IoT 业务核心模块（本项目新增）
│   ├── config/          # MQTT、TDengine 配置
│   ├── controller/      # 13 个 REST Controller
│   ├── domain/          # 10 个实体类
│   ├── mapper/          # 9 个 MyBatis Mapper
│   └── service/         # 16 个业务服务
├── ruoyi-system         # 系统管理（用户/角色/菜单/日志）
├── ruoyi-framework      # 框架核心
├── ruoyi-common         # 公共工具
├── ruoyi-quartz         # Quartz 定时任务
└── ruoyi-generator      # 代码生成器
```

### 2.3 数据库架构

| 数据库类型 | 产品 | 存储内容 |
|-----------|------|---------|
| 时序数据库 | TDengine | 传感器实时数据、小时/日聚合数据 |
| 关系型数据库 | PostgreSQL + PostGIS | 用户/角色/菜单、大棚/设备/物候期/阈值、告警记录、GIS 空间数据 |
| 缓存 | Valkey | 传感器实时值、设备状态、设备心跳、告警去重队列 |

### 3.2 快速部署（Docker 一键启动）

```bash
# 1. 进入项目目录
cd dongzao

# 2. 启动所有中间件服务
docker compose up -d

# 启动的服务清单：
# - PostgreSQL 16   → 端口 5432
# - TDengine 3.x    → 端口 6030/6041
# - Valkey 8        → 端口 6379
# - Mosquitto 2.x   → 端口 1883

# 3. 打包后端
mvn clean package -DskipTests

# 4. 启动后端
java -jar backend/ruoyi-admin/target/ruoyi-admin.jar

# 启动后访问：http://localhost:8080
# 默认登录：admin / admin123
```

## 五、MQTT 数据协议

### 5.1 连接参数

| 参数 | 值 |
|------|-----|
| Broker 地址 | `tcp://服务器IP:1883` |
| 订阅主题 | `dongzao/greenhouse/#` |
| QoS 级别 | 1（至少一次送达） |
| 客户端 ID | `dongzao-server_{时间戳}` |

### 5.2 消息格式

```json
{
  "greenhouse_id": "GH001",
  "sensor_type": "temperature",
  "value": 28.5,
  "unit": "℃",
  "timestamp": "2026-06-04 18:30:00",
  "status": "normal",
  "location": "center"
}
```

### 5.3 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| greenhouse_id | String | 是 | 大棚唯一标识，如 GH001 |
| sensor_type | String | 是 | 传感器类型 |
| value | Number | 是 | 传感器数值 |
| unit | String | 是 | 单位 |
| timestamp | String | 是 | 格式 yyyy-MM-dd HH:mm:ss |
| status | String | 是 | normal/warning/critical |
| location | String | 否 | 位置 center/north/south/east/west |

### 5.4 传感器类型列表

| 传感器类型 | 说明 | 单位 | 物理范围 |
|-----------|------|------|---------|
| temperature | 空气温度 | ℃ | -40 ~ 80 |
| humidity | 空气湿度 | % | 0 ~ 100 |
| light | 光照强度 | lux | 0 ~ 100000 |
| soil_moisture | 土壤湿度 | % | 0 ~ 100 |
| co2 | CO₂浓度 | ppm | 0 ~ 5000 |
| ph | pH值 | - | 0 ~ 14 |
| wind_speed | 风速 | m/s | 0 ~ 50 |
| soil_temperature | 土壤温度 | ℃ | -20 ~ 60 |

## 六、数据流说明

### 6.1 主数据流（MQTT 实时链路）

```
传感器/模拟器
     │ MQTT Publish (dongzao/greenhouse/#)
     ▼
EMQX MQTT Broker
     │ MQTT Subscribe
     ▼
MqttConsumer (Java)
  ├─ DataQualityChecker     → 物理范围校验/变化率校验/冗余校验
  ├─ TDengineClient         → TDengine 时序库写入
  ├─ RealtimeCacheService   → Valkey 缓存更新
  └─ AlarmEngine            → 阈值预警/变化率预警检查
       └─ 触发告警 → PostgreSQL 写入 → AlarmPushService 推送
```

### 6.2 备用数据流（HTTP 链路）

```
ESP32/边缘网关
     │ HTTP POST
     ▼
GateWayController (/iot/gateway/report)
  └─ 处理流程与 MQTT 链路完全一致
```

### 6.3 查询数据流

```
Vue前端
     │ REST API
     ▼
Controller → Service
  ├─ TDengine       → 时序数据查询
  ├─ PostgreSQL     → 业务数据查询
  └─ Valkey         → 实时数据/设备状态查询
```

### 6.4 自动化任务流

```
Gateway（外部定时器）
     │ HTTP POST
     ▼
ReportController
  ├─ POST /daily         → OpenClawService → EasyExcel → 阿里云OSS
  ├─ POST /inspect       → OpenClawService → TDengine → 数据质量预警
  ├─ POST /alarm/agg     → OpenClawService → PostgreSQL → 告警聚合
  └─ POST /reminder      → OpenClawService → 物候期 → 农事提醒
```

## 九、告警处理流程

### 9.1 6 大类预警

| 预警类型 | 检测方法 | 触发时机 |
|---------|---------|---------|
| 阈值预警 | 参数值超过预设上下限 | MQTT 实时 |
| 变化率预警 | 1 分钟内变化速率超过阈值 | MQTT 实时 |
| 统计预警（3σ法则） | 偏离历史同期均值 ±3σ | 每小时 |
| 数据质量预警 | 完整率<95%/80%，异常占比>5%/15% | 每小时 |
| 设备状态预警 | 心跳超时/网关失联/低电量 | 每5分钟 |
| 物候期预警 | 参数偏离物候期适宜区间 | 每5分钟 |

### 9.2 四级预警级别

| 级别 | 颜色 | 响应时间 |
|------|------|---------|

## 十一、常见问题

### 11.1 启动报数据库连接失败

**现象**：`Connection to localhost:5432 refused`
**原因**：本地未运行 PostgreSQL
**解决**：
```bash
# 启动本地 Docker PostgreSQL
docker compose up -d postgres

# 或用环境变量指向远程
$env:SPRING_DATASOURCE_DRUID_MASTER_URL="jdbc:postgresql://10.131.67.102:5432/dongzao_db"
java -jar target/ruoyi-admin.jar
```

### 11.2 MQTT 连接失败

**检查**：`application.yml` 中 `mqtt.broker` 配置是否正确，EMQX 服务是否运行

### 11.3 TDengine 连接失败

**验证**：
```bash
curl -u dongzao:Td2026@Taos -d "SHOW DATABASES;" http://10.131.67.102:6041/rest/sql
```

### 11.4 登录失败

**检查**：是否执行了 `add_base_admin_role.sql`，Redis 中是否缓存了旧权限信息

### 11.5 接口返回 403

**原因**：权限不足或 Token 过期
**解决**：重新登录获取新 Token，必要时清除 Redis 缓存

### 11.6 Swagger 接口文档

启动后端后访问：`http://localhost:8080/swagger-ui.html`
